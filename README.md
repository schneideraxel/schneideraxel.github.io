A personal academic website using Quarto’s default theme and fonts with a simple
responsive two-column layout: a profile sidebar on the left and a reading column
on the right, inspired by Academic Pages and Minimal Mistakes.
Edit content in `index.qmd`, styling in `styles.css`, and metadata in `_quarto.yml`.
The square portrait displays in color. Typography uses Quarto’s sans-serif font
with compact sizing and a muted palette inspired by the Minimal Mistakes Dirt
skin. The original image is unchanged.

## Preview and build

```sh
quarto preview
quarto render
```

The rendered site is written to `docs/` for GitHub Pages. Only `index.qmd` is
rendered; design experiments in `previews/` are not site pages.

## Update content

Research entries describe unfinished work and retain explicit status labels.
Update collaborators, descriptions, and status in `index.qmd` as projects evolve.
No CV or draft documents are currently hosted. The Code section follows education and links small shared projects to their
public GitHub repositories.
